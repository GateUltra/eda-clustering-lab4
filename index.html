Sources and changes

The original five-node graph, module topic, and required parameter comparisons come from Yongfu Li’s EDA learning course. This maintainer edition supplies a newly written English lesson, newly synthesized narration, bilingual captions, diagrams, browser engine, and Python exercises.

Our deterministic tie-break compares sorted member lists. The upstream implementation uses synthetic identifiers such as C0. We do not claim universal merge-trace equivalence. The upstream source inspected also lacks an explicit positive-affinity filter; this edition explicitly excludes zero-affinity merges.
